# Ender Flynnies 2
Welcome to Ender Flynnies 2, this game is a sequel to the original Ender Flynnies made in 2025.</br>
Expect this game to be released Summer 2027</br>
# What do i need to be able to run the game?
Ender Flynnies 2 will only be supported on Windows 10 / 11 </br>
## Minimum requirements:
1 GB RAM </br>
1 GB Storage </br>
Intel i3 / AMD Ryzen 3 </br>
Integrated graphics </br>

## Recommended system specs:
2 GB RAM </br>
4 GB Storage </br>
Intel i5 / AMD Ryzen 3 </br>
Dedicated GPU </br>

## Required software:
Windows 10 / 11 <br>
Python 3.13.7 (3.14.x and higher is not supported) (Enable 'Add to PATH' option if on Windows)</br>
Pygame 2.6.1 (Can be installed using 'pip install pygame') </br>
